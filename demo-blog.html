My First Months of Learning to Code

I started learning to code in September. At first, HTML and CSS felt like writing a very strict letter, where one missing bracket can break the whole page.

Then JavaScript made the pages come alive. My biggest lesson so far is to build small and test often. Every time I add one feature and check it, I understand the code better. I also learned that reading error messages slowly usually points you straight to the problem.

November 2026 Security

Why Strong Passwords Still Matter

A password is the front door to your accounts. A short, simple password is like a door that anyone can open with a little patience.

Length matters more than clever symbols, so a long phrase of random words is stronger than a short word with a few numbers. Use a different password for every account, so one leak does not open everything. A password manager can remember them for you, and turning on two-step verification adds a second lock.

October 2026 Security

How to Spot a Phishing Email

Phishing emails try to trick you into giving away passwords or money. They often look like they come from a bank, a school or a company you know.

Check the sender's address carefully, because the name can look right while the address is strange. Be suspicious of messages that create panic, such as "your account will be closed today". Hover over links to see where they really go, and never open attachments you did not expect. When in doubt, contact the company using a number or website you already trust.
