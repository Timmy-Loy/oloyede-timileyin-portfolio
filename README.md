# Student Portfolio and Academic Management Website

**COS 106 – Introduction to Web Technologies | Lab Assessment**
**Author:** Timileyin Oloyede, MIVA Open University

A responsive multi-page website that works as my personal academic portfolio and a simple student planner. It was built with HTML, CSS and JavaScript only (no frameworks).

**Live site:** _add your Netlify link here_

## Pages

| Page | File | What it does |
|------|------|--------------|
| Home | `index.html` | Photo, welcome message, short biography and quick links |
| About Me | `about.html` | Education table, career aspirations, technical skills and hobbies |
| Projects | `projects.html` | Three sample projects with descriptions, images and links |
| Academic Planner | `planner.html` | Add, complete and delete tasks (saved in the browser) |
| Contact | `contact.html` | Contact details and a form with JavaScript validation |

## Features

- Responsive layout that works on phones, tablets and computers (Flexbox and CSS Grid)
- Mobile menu, hover effects and animations
- Interactive planner built with arrays, functions, event handling and DOM manipulation
- Contact form validation: no empty fields, valid email format, phone number digits only
- Background ambient sound with an on/off button
- Semantic HTML with a table, lists, images, links and audio

## How to run it

1. Download or clone this repository.
2. Open `index.html` in any web browser.

No installation is needed.
